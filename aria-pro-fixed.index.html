📲 Install Aria Pro
Android · Chrome Browser
1Open your Aria link in Chrome on Android
2Tap the ⋮ three dots menu in the top right corner
3Tap "Add to Home Screen"
4Tap "Add" to confirm
5🎉 Aria icon appears on your home screen!
💡 Or look for the install popup that Chrome shows at the bottom of the screen automatically!
iPhone / iPad · Safari Browser
1Open your Aria link in Safari on iPhone/iPad
2Tap the Share button (box with arrow ↑) at the bottom
3Scroll down and tap "Add to Home Screen"
4Edit the name if you want, then tap "Add"
5🎉 Aria icon appears on your iPhone home screen!
⚠️ Must use Safari — Chrome on iPhone doesn't support "Add to Home Screen" properly.
Windows / Android · Microsoft Edge
1Open your Aria link in Microsoft Edge
2Look for the install icon (⊕ or computer icon) in the address bar
3Click it and select "Install"
4Or tap ⋯ menu → Apps → Install this site as an app
5🎉 Aria opens like a real desktop/phone app!
💡 On Windows, Aria will appear in your Start Menu and taskbar just like a real app!
